# URL Encoder/Decoder API — Privacy-First, Zero Tracking

Free percent-encoding encode/decode at the edge. **No tracking, no data collection, no logs** — by [formatho.com](https://formatho.com/url-encoder-decoder), privacy-first developer tools.

## Usage

```bash
curl "https://url-encoder-formatho.workers.dev/?text=hello%20world&action=decode"
curl "https://url-encoder-formatho.workers.dev/?text=https://formatho.com/?q=a+b&action=encode"
```

Parameters: `text` (required), `action` — `encode` (default) or `decode`.

## Why privacy-first?

Nothing is stored or logged. For a full browser-based URL tool (100% client-side), see the [Formatho URL Encoder/Decoder](https://formatho.com/url-encoder-decoder).
